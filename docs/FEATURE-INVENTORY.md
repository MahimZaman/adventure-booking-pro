# Feature inventory

**Implemented** means registration reaches an implementation in this checkout. **Partial** means a specific part of the workflow is missing or limited. **Unused** identifies an inert artifact. **Unverified** identifies a dependency on site configuration or runtime behavior for which source review provides insufficient evidence. These statuses describe static evidence. No live booking was placed.
